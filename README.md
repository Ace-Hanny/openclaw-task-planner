# OpenClaw Task Planner

> 🍅 任务规划系统 - 番茄钟 + 多维表格 + AI 规划 + 闭环优化

## 核心价值

### 🔄 完整的任务闭环

**不是简单的番茄钟，而是一个会学习的计划系统。**

```
计划 → 执行 → 记录 → 分析 → 优化
  ↑                              ↓
  └──────────────────────────────┘
```

| 环节 | 功能 | 数据来源 |
|------|------|----------|
| **计划** | AI 自动生成日计划 | 飞书日历 + 飞书任务 + 周计划 |
| **执行** | 番茄钟专注计时 | 多维表格日计划表 |
| **记录** | 自动记录执行数据 | 执行记录表 |
| **分析** | 计划 vs 执行对比 | 偏差分析表 |
| **优化** | 学习用户习惯 | 历史数据分析 |

### 📊 多数据源整合

**一键同步你的所有待办：**

| 数据源 | 同步内容 | 用途 |
|--------|----------|------|
| 飞书日历 | 今日行程 | 标记为「不可变」时间块 |
| 飞书任务 | 待办事项 | 按优先级安排 |
| 周计划 | 每日任务 | 从周目标拆分 |
| 延续任务 | 昨日未完成 | 自动追踪 |

### 🧠 AI 辅助规划

- **日计划自动生成** - 每日 8:00 推送，整合所有待办
- **智能时间安排** - 根据行程、优先级、习惯自动分配时间块
- **延续任务处理** - 未完成任务自动延续，用户确认后执行

### 📈 偏差分析与习惯学习

**系统会越来越懂你：**

- 哪个时段效率最高？
- 某类任务实际需要多长时间？
- 哪些情况容易被打断？
- 哪些任务经常超时？

**分析结果自动优化后续计划。**

## 功能特性

- 🍅 **番茄钟计时器** - 25分钟专注 + 5分钟休息
- 📊 **飞书多维表格集成** - 任务管理 + 执行记录
- 📅 **多数据源同步** - 日历 + 任务 + 周计划
- 🤖 **AI 日计划生成** - 自动整合待办，智能安排时间
- 🔄 **延续任务追踪** - 未完成任务自动延续
- 📈 **统计分析** - 今日/本周/本月专注时长
- 🧠 **习惯学习** - 分析执行数据，优化计划策略

## 快速开始

### 方式一：一键安装（推荐）

```bash
curl -fsSL https://raw.githubusercontent.com/Ace-Hanny/openclaw-task-planner/main/scripts/install.sh | bash
```

### 方式二：手动安装

```bash
# 1. 克隆仓库
git clone https://github.com/Ace-Hanny/openclaw-task-planner.git
cd openclaw-task-planner

# 2. 安装依赖
cd pomodoro
npm install

# 3. 配置
cp config.example.json config.json
# 编辑 config.json，填入飞书应用凭证

# 4. 启动
npm start
```

访问 http://localhost:9998

## 配置说明

### 1. 创建飞书应用

1. 访问 https://open.feishu.cn/app
2. 创建企业自建应用
3. 获取 App ID 和 App Secret

### 2. 配置应用权限

必需权限：
- `bitable:record:read` - 读取多维表格记录
- `bitable:record:write` - 写入多维表格记录
- `task:task:read` - 读取任务

### 3. 创建多维表格

参考 `templates/bitable-structure.json` 创建：
- 日计划表
- 执行记录表

详细配置见 [docs/installation.md](docs/installation.md)

## 使用流程

### 1. 日计划确认

每日 8:00 收到日计划初稿：
- 今日行程（飞书日历）
- 待办任务（飞书任务）
- 周计划任务
- 延续任务（昨日未完成）

确认后写入多维表格，番茄钟自动读取。

### 2. 番茄钟执行

- 选择任务开始专注
- 25分钟后自动记录执行数据
- 支持统计查看

### 3. 偏差分析

- 每日 22:00 自动复盘
- 对比计划 vs 执行
- 分析偏差原因
- 优化后续计划
